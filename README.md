# The To-Do List

This is my very first project! It allows you to manage tasks easily by adding them with a title, description, and timestamp, and moving them between stages as you progress.

## Built with Vanilla JavaScript

- A simple project created using Vanilla JavaScript.
- Styled with the Sass preprocessor and enhanced with animations.

## Features ✨

- **Add tasks** with a title, description, and creation timestamp.
- **Move tasks** between stages: To Do, In Progress, and Done.
- **Modal** for viewing already existing tasks.
- Clean and user-friendly design.
